# Portfólio Miguel Cardoso

Este repositório é a fonte central de verdade do projeto oficial do portfólio pessoal de Miguel Cardoso.

O projeto encontra-se em fase de levantamento e planeamento. Ainda não existe aplicação implementada, frontend, backend, base de dados, sistema de autenticação, componentes ou funcionalidades em produção.

## Conceito

O portfólio deve funcionar como:

**Portfólio profissional + hub pessoal**

O objetivo não é criar apenas um CV online, mas sim uma presença digital pessoal que apresente quem é o Miguel, aquilo que faz, aquilo que gosta e aquilo que cria.

## Posicionamento

> Sou estudante de Engenharia Informática, interessado em desenvolvimento, tecnologia e criação de conteúdo.

## Público-alvo

O público principal inicial será composto por seguidores e público geral, especialmente pessoas provenientes do Instagram. O site deve ser claro para amigos, familiares, conhecidos, seguidores e visitantes sem conhecimentos técnicos.

O público secundário inclui recrutadores, empresas, profissionais de tecnologia, programadores, potenciais clientes, colaboradores e parceiros profissionais.

A experiência deve permitir profundidade progressiva: leitura simples para visitantes comuns e detalhe técnico para visitantes profissionais.

## Áreas principais em planeamento

As áreas conceptuais inicialmente definidas são:

- Tecnologia.
- Fotografia.
- Fitness.

Tecnologia e Fotografia têm maior peso. Fitness representa sobretudo um interesse pessoal. A arquitetura futura não deve assumir que estas áreas são permanentes ou únicas; novas áreas como Gaming, Viagens ou outras poderão surgir mais tarde.

## Home page conceptual aprovada

A Home deverá seguir uma abordagem minimalista e pessoal, com esta estrutura conceptual:

1. Hero.
2. Explora.
3. Sobre mim.
4. Projetos em destaque.
5. Fotografia/criação.
6. Contacto.
7. Footer.

A implementação visual detalhada ainda não foi definida.

## Stack tecnológica

Decisões atuais:

- Backend: Python confirmado como linguagem.
- PHP: não será utilizado.
- Django: possibilidade a avaliar na fase de arquitetura técnica, especialmente pela gestão de conteúdo.
- Base de dados: decisão final pendente; PostgreSQL continua uma possibilidade preliminar.
- Frontend: HTML5, CSS3 e JavaScript fazem parte da base prevista, mas a arquitetura final será definida mais tarde.

Não instalar dependências nem iniciar implementação nesta fase.

## Idiomas

- Português de Portugal (PT-PT), idioma principal.
- English (EN).
- Français (FR).

A arquitetura deverá permitir tradução organizada sem duplicar a aplicação.

## Filosofia do projeto

- Minimalismo sem ser vazio.
- Criatividade sem ser exagerada.
- Simplicidade antes de complexidade.
- Conteúdo separado da apresentação sempre que fizer sentido.
- Documentação como memória oficial do projeto.
- Independência face a qualquer ferramenta de IA.
