# Portfolio Pessoal

Projeto provisório para um portfólio pessoal web profissional, minimalista, seguro, documentado e preparado para evolução futura.

## Estado atual

Este projeto encontra-se em fase de planeamento e pré-desenvolvimento.

Ainda não existe aplicação implementada. Não existem funcionalidades de software concluídas, código Django, modelos de base de dados, frontend, autenticação ou integração com serviços externos.

## Objetivo

Criar a base documental e estrutural para um futuro website de portfólio pessoal, mantendo o repositório como fonte de verdade para programadores humanos e ferramentas de Inteligência Artificial.

## Stack tecnológica planeada

- Python
- Django
- PostgreSQL
- HTML5
- CSS3
- JavaScript

A stack é preliminar e deve ser detalhada em documentação própria antes da implementação.

## Filosofia do projeto

O projeto privilegia simplicidade, legibilidade, segurança, documentação e evolução controlada. Nenhuma ferramenta de IA é fonte de verdade. A fonte de verdade é o repositório GitHub e a documentação nele mantida.
