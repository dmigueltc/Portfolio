# Arquitetura

Documentação de arquitetura do projeto.

Nesta fase existem várias camadas de arquitetura documental: arquitetura conceptual, arquitetura da informação, decisões e proposta inicial de arquitetura técnica.

Documentos principais:

- `information-architecture.md`
- `sitemap-v1.md`
- `technical-architecture-v1.md`
- `decisions/decision-log.md`

O documento `technical-architecture-v1.md` representa a proposta inicial de arquitetura técnica para a fase de planeamento e decisão. Não define implementação final, nem tecnologias definitivas em todas as áreas, mas estabelece uma base clara para implementação futura.

Não criar implementação técnica, modelos, serviços, componentes ou integrações nesta fase.
