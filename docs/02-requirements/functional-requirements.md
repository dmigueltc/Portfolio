# Requisitos Funcionais

O levantamento detalhado de requisitos funcionais está em curso.

Este documento deve registar apenas requisitos funcionais quando forem propostos, aprovados, rejeitados ou classificados para futuro. Nesta fase, as possibilidades identificadas no levantamento não devem ser tratadas como requisitos definitivos.

## Formato de registo

```text
ID:
RF-XXX

Nome:

Descrição:

Prioridade:
Alta / Média / Baixa

Estado:
Proposto / Aprovado / Rejeitado / Futuro

Dependências:

Observações:
```

## Priorização futura

- Must Have: obrigatório para a primeira versão.
- Should Have: importante, mas pode ser desenvolvido depois.
- Could Have: interessante, mas não essencial.
- Won't Have — V1: não fará parte da primeira versão.

## Requisitos aprovados

Não existem requisitos funcionais aprovados nesta fase.

## Decisões pendentes

- Estrutura de páginas e secções.
- Forma de apresentação de projetos.
- Gestão administrativa de conteúdo.
- Galeria ou estrutura de fotografia.
- Conteúdo de vídeo e origem dos vídeos.
- Contacto e proteção contra spam.
- Funcionalidades futuras como pesquisa, filtros, blog, analytics, newsletter, API pública, PWA, dark mode ou outras.
