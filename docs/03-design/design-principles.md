# Princípios de Design

Este documento define a direção visual aprovada para o portfólio Miguel Cardoso. Não contém implementação visual, CSS, componentes ou layout final.

## Direção escolhida

Minimalista pessoal/criativa.

Princípio geral:

> Minimalismo sem ser vazio; criatividade sem ser exagerada.

## Valores visuais

- Clean.
- Minimalista.
- Profissional.
- Pessoal.
- Criativo.
- Com bastante espaço visual.
- Excelente legibilidade.
- Confortável para os olhos.
- Moderno sem estética tecnológica exagerada.

## Evitar

- Excesso de elementos.
- Excesso de cores.
- Animações excessivas.
- Design visualmente cansativo.
- Complexidade visual desnecessária.
- Funcionalidades visuais apenas porque são tecnicamente interessantes.

## Referência conceptual

Foi usada como referência conceptual uma filosofia visual minimalista semelhante a:

`https://diogotc.com/`

Esta referência não deve ser copiada. Não copiar design, layout, código, identidade visual, estrutura exacta ou conteúdo.

## Cores

A paleta final ainda não foi definida.

Direção atual:

- neutra;
- poucas cores;
- confortável para os olhos;
- profissional;
- sem cores excessivamente fortes.

## Tokens de design

As cores devem ser centralizadas através de tokens ou variáveis de design.

Exemplo conceptual:

```text
--color-background
--color-surface
--color-text
--color-text-muted
--color-border
--color-accent
```

Regra:
Não espalhar valores de cores diretamente por muitos ficheiros.

## Light/Dark mode

Light/Dark mode ainda não está decidido.

A arquitetura pode permitir evolução futura, mas não implementar múltiplos temas prematuramente.

## Imagem pessoal e logótipo

Decisão atual:

- Não será usada fotografia pessoal inicialmente.
- Não será usado logótipo inicialmente.

A estrutura deve permitir adicionar ambos futuramente sem comprometer a arquitetura.

## Interação

- Interações devem ser subtis.
- Hover pode enriquecer a experiência em desktop.
- Funcionalidade essencial não pode depender de hover, porque mobile não tem hover.
- Animações, se aprovadas futuramente, devem ser discretas e respeitar acessibilidade.
