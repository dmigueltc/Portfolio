# Contexto do Projeto para IA

## Objetivo

Preparar um futuro website de portfolio pessoal profissional, minimalista, seguro, documentado e preparado para evolucao.

## Visao

O projeto deve permitir continuidade por diferentes programadores ou ferramentas de IA sem perda de contexto. A fonte de verdade e o repositorio GitHub e a documentacao nele existente.

## Stack planeada

- Python
- Django
- PostgreSQL
- HTML5
- CSS3
- JavaScript

## Idiomas

- Portugues de Portugal (PT-PT), idioma principal
- English
- Francais

## Arquitetura planeada

Backend em Python/Django e base de dados PostgreSQL estao planeados. A arquitetura detalhada ainda nao foi aprovada e nao deve ser inventada nesta fase.

## Estado

- Versao: 0.1.0
- Fase: Planeamento
- Estado: Pre-desenvolvimento

## Principios

- Simplicidade antes de complexidade.
- Codigo legivel.
- Seguranca desde o inicio.
- Documentacao obrigatoria.
- Independencia face a ferramentas de IA especificas.
- Sem dependencias novas sem justificacao.
- Sem alteracoes arquiteturais sem autorizacao e documentacao.

## Funcionalidades previstas

As funcionalidades concretas ainda serao definidas no levantamento de requisitos. Nao existem funcionalidades aprovadas ou implementadas nesta fase.

## Limitacoes atuais

- Nao existe aplicacao implementada.
- Nao existem modelos de base de dados.
- Nao existe frontend.
- Nao existe autenticacao.
- Nao existem requisitos funcionais definitivos.
- Nao existem decisoes arquiteturais definitivas.
