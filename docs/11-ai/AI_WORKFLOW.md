# Workflow para IA

Fluxo recomendado para qualquer trabalho assistido por IA:

1. Contexto
2. Requisitos
3. Arquitetura
4. Implementacao
5. Testes
6. Documentacao
7. Commit

## Contexto

Ler a documentacao central antes de propor alteracoes.

## Requisitos

Confirmar que a alteracao esta alinhada com requisitos aprovados. Se os requisitos nao existirem, propor documentacao antes de implementar.

## Arquitetura

Consultar decisoes existentes em `docs/04-architecture/`. Nao criar ou alterar arquitetura sem autorizacao.

## Implementacao

Fazer alteracoes pequenas, focadas e alinhadas com o projeto.

## Testes

Executar ou propor testes adequados ao tipo de alteracao.

## Documentacao

Atualizar documentacao afetada pela alteracao.

## Commit

Criar commits claros, com mensagens objetivas e escopo limitado.
