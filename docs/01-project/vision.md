# Visao

Criar um portfolio pessoal web profissional, minimalista, seguro e preparado para evolucao futura.

O projeto deve ser documentado desde o inicio para permitir continuidade por diferentes programadores ou ferramentas de IA sem perda de contexto.

O website tera Portugues de Portugal como idioma principal e devera suportar tambem English e Francais.

## Fonte de verdade

A fonte de verdade sera o repositorio GitHub e a documentacao nele existente.
