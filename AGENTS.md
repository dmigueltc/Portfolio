# Instruções para Agentes

Este projeto pode ser trabalhado por diferentes programadores ou agentes de IA. O repositório e a documentação são a fonte de verdade.

Antes de qualquer alteração:

1. Ler `PROJECT_CONSTITUTION.md`.
2. Ler `PROJECT_STATUS.md`.
3. Ler `docs/11-ai/PROJECT_CONTEXT.md`.
4. Consultar `docs/04-architecture/decisions/decision-log.md`.
5. Consultar os requisitos relevantes.
6. Consultar a arquitetura relevante.
7. Não alterar decisões importantes sem autorização.
8. Testar alterações quando existir código testável.
9. Atualizar documentação quando necessário.
10. Manter alterações pequenas e focadas.
11. Não modificar ficheiros não relacionados.

## Regras de trabalho

- Não desenvolver funcionalidades fora do escopo aprovado.
- Não introduzir dependências sem justificação.
- Não criar dados, biografias, projetos ou conteúdo fictício.
- Não tratar qualquer ferramenta de IA como fonte de verdade.
- Registar decisões relevantes no decision log.
- Não assumir Django, PostgreSQL, gestão de conteúdo, tema visual ou integrações como decisões finais quando estiverem marcadas como pendentes.
