# Constituicao do Projeto

Este documento define as regras fundamentais do projeto. Deve ser consultado antes de qualquer alteração relevante.

## Principios fundamentais

- Simplicidade antes de complexidade.
- Codigo legivel, claro e facil de manter.
- Seguranca considerada desde o inicio.
- Documentacao obrigatoria para decisoes, requisitos e alteracoes relevantes.
- Portugues de Portugal (PT-PT) como idioma principal do website.
- English e Francais como idiomas adicionais.
- Python e Django como backend planeado.
- PostgreSQL como base de dados planeada.
- Dependencias novas apenas com justificacao documentada.
- Arquitetura apenas deve ser alterada com documentacao e autorizacao.
- Nao criar conteudo ficticio como se fosse real.
- Nao depender de uma IA especifica.

## Fonte de verdade

A fonte de verdade do projeto e o repositorio GitHub e a documentacao nele existente.

Ferramentas como ChatGPT, OpenAI Codex, Claude, Gemini, GitHub Copilot ou outras podem apoiar o trabalho, mas nao substituem a documentacao do projeto.

## Alteracoes futuras

Qualquer alteracao relevante deve respeitar:

- o estado atual do projeto;
- os requisitos aprovados;
- as decisoes de arquitetura documentadas;
- as regras de seguranca;
- o historico registado no changelog.
